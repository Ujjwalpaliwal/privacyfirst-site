Terminal (prifir CLI)
Run the prifir CLI

The CLI gives you full control from the terminal — start and stop the proxy, check status, and undo config changes. Not published to npm yet; run it from a local checkout.

npm run build # once, from the repo node packages/cli/bin/prifir.js # launches interactive wizard node packages/cli/bin/prifir.js status # show current protection state node packages/cli/bin/prifir.js off # stop proxy + remove configs node packages/cli/bin/prifir.js undo # restore all backed-up configs

Quickstart

In 3 steps

01
Download and open the app
The proxy starts automatically on 127.0.0.1:4040.
02
In Settings, enable Auto-protect
PrivacyFirst previews the exact config changes and writes them with a backup.
03
Open your AI coding tool normally
All outgoing requests are now intercepted and sanitized.
