Technical Breakdown

How PrivacyFirst works

Engine Pipeline

Detect → Resolve → Vault → Sanitize

01
Detect

All 12 detectors run regex passes over the input text simultaneously. Validators (Verhoeff, Luhn) discard false positives before any span is recorded.

02
Resolve overlaps

Spans are sorted by position. Overlapping detections keep the longest match. A PAN that matches inside a longer string yields to the encompassing detector.

03
Vault

Each unique value is normalized (whitespace stripped, digits-only for cards/Aadhaar) before lookup. Duplicate originals get the same placeholder — 2345 6789 0124 and 234567890124 both map to [AADHAAR_01].

04
Sanitize

Text is rebuilt by replacing detected spans left-to-right. The sanitized string is what gets sent to the AI.

Input A : "2345 6789 0124" → normalize → "234567890124" Input B : "2345-6789-0124" → normalize → "234567890124" Both map to [AADHAAR_01]
Stream Restorer

Handling chunked SSE responses

AI APIs stream responses as Server-Sent Events. A placeholder like [PERSON_01] may arrive split across chunk boundaries — e.g. [PER in chunk 4 and SON_01] in chunk 5. The stream restorer buffers incomplete bracket sequences and only emits confirmed complete tokens.

Chunk 4: "Hello [PER" → buffered (bracket open, no close) Chunk 5: "SON_01], how" → flush: "Hello Rahul Sharma, how" Chunk 6: " are you?" → emit as-is

accept-encoding Always identity — disables upstream compression for reliable body parsing

Security

What the proxy does and doesn't do

Does
  • [+] Binds to 127.0.0.1 only
  • [+] Passes all original headers through
  • [+] Never stores API keys
  • [+] CSP: no inline eval, no external resources
  • [+] Proxy log stores metadata only — no original text
Doesn't
  • [-] Doesn't intercept HTTPS between tools and proxy (loopback only)
  • [-] Doesn't log request bodies
  • [-] Doesn't store vault entries to disk (memory-only)
  • [-] Doesn't support multi-user or remote access
Auto-Protect

Exact file changes, previewed before applied

When you enable Auto-protect in Settings (or run prifir), PrivacyFirst detects installed tools and writes minimal configuration. Every file is backed up to ~/.privacyfirst/backups/<timestamp>/ before being touched.

Tool File written What's added
opencode opencode.json provider.anthropic.options.baseURL
= "http://127.0.0.1:4040/v1"
Claude Code ~/.claude/settings.json env.ANTHROPIC_BASE_URL
= "http://127.0.0.1:4040"
Codex ~/.codex/config.toml openai_base_url
= "http://127.0.0.1:4040/v1"
Merge strategy: existing keys are never overwritten. Only the base-URL key is added. Original file backed up with timestamp.
Note the per-tool URL convention: opencode and Codex expect the /v1 suffix, Claude Code expects the bare origin.
